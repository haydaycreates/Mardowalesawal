## Verification

`npm test` checks JSON loading, IDs, fields, chapter coverage, numbered solutions, balanced math delimiters, accidental JSON control-character escapes, and strict KaTeX rendering of every math expression. Numerical checks independently verify the new definite integrals/areas, indefinite-integral derivatives, and differential-equation solutions. These checks supplement the analytical working; they do not certify historical attribution beyond the sources above.

The q11–q22 tests also check topic coverage and the seven-field schema, differentiate the proposed functions numerically, verify related-rate and optimisation calculations, check matrix cofactors/inverses and solution vectors, and test the determinant identities. All LaTeX expressions, including matrix and piecewise row separators, are rendered with strict KaTeX parsing.

The q23–q28 checks enumerate the two-stage bird-transfer outcomes, check joint/total/conditional form-error probabilities, test equivalence-relation properties on a finite sample, verify inverse-function compositions, and check cross products, distances, perpendicularity and reflection coordinates. The general relation and bijection proofs are provided analytically in the solutions. JSON is additionally checked with Python’s JSON parser and JavaScript `JSON.parse`.
